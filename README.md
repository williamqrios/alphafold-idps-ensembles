# README

- `md` = molecular dynamics input files (`inputs`), bash scripts (`bash_scripts`), python analysis scripts (`analysis`), simulation-derived raw timeseries (`data`)
  - for force field parameters, see https://github.com/paulrobustelli/Force-Fields (a99disp) and https://mackerell.umaryland.edu/charmm_ff.shtml (`charmm36-jul2022.ff.tgz`)
  - raw GROMACS trajectory files (`.xtc`) stripped of non-protein entities (water molecules and ions) can be downloaded from https://doi.org/10.5281/zenodo.22301918
- `af2` = alphafold2 generated structures
